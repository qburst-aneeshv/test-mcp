# Contributing

Thank you for your interest in contributing to this MCP server project!

## How to Contribute
- Fork the repository and create your branch (e.g., `feature/my-feature`).
- Make your changes and write clear commit messages.
- Ensure your code follows the style and guidelines of the project.
- Submit a pull request for review.

## Code of Conduct
Please be respectful and follow the [Code of Conduct](./CODE_OF_CONDUCT.md) in all interactions.

## Issues
If you find a bug or have a feature request, please open an issue with details and steps to reproduce.
